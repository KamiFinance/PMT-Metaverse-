# Step 1 — Install Unreal Engine 5.3

## What you need
- Windows 10/11 or macOS 12+ (Windows recommended for UE5)
- GPU: NVIDIA RTX 2070 or better (minimum), RTX 3080+ (recommended)
- RAM: 32 GB minimum
- Storage: 200 GB free (UE5 is large)
- Internet: fast connection for the 100 GB download

## Install steps

1. Go to **https://www.unrealengine.com** → click **Download**
2. Create a free Epic Games account
3. Install the **Epic Games Launcher**
4. In the Launcher, click **Unreal Engine** tab on the left
5. Click **+** next to Engine Versions
6. Select **5.3** (not 5.4+ yet — our config targets 5.3)
7. Click **Install** — this downloads ~100 GB, takes 1–3 hours

## While it downloads, install these too:

### Git + Git LFS
- Windows: https://git-scm.com/download/win
- After install, open terminal: `git lfs install`

### Node.js 20
- https://nodejs.org → download LTS (v20)

### MetaMask browser extension
- https://metamask.io → Add to Chrome/Firefox

## Verify UE5 installed
1. Open Epic Games Launcher
2. Click **Launch** next to Unreal Engine 5.3
3. It should open with the Unreal Project Browser
